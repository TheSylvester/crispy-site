# crispy-site

Permanent archive page for **Crispy** — a GUI for Claude Code and Codex, built for multi-agent orchestration. Crispy is sunsetted; its successor is [Recall](https://github.com/TheSylvester/crispy-recall).

Static Next.js site served at **[crispy.thesylvester.ca](https://crispy.thesylvester.ca)** via GitHub Pages (see `.github/workflows/deploy.yml`).

```bash
pnpm dev      # local dev server
pnpm build    # static export → out/
```
